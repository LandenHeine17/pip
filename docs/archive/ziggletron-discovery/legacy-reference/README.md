# Legacy Reference (non-authoritative)

This folder holds **source-level evidence** gathered during discovery of the current Ziggletron. It exists so that claims in the main discovery documents can be checked against the old code.

- [FEATURE-TO-CODE-INDEX.md](FEATURE-TO-CODE-INDEX.md): which legacy files and tests support each `FEAT-nnn`, plus the command, action, HTTP and file inventories.
- [TECHNICAL-AUDIT-NOTES.md](TECHNICAL-AUDIT-NOTES.md): architectural observations, source evidence for problems listed in `KNOWN-PROBLEMS-AND-LIMITATIONS.md`, and technical limitations.

**Rules for using this folder:**
1. It is historical and descriptive. It is **not** a design, and nothing here is a requirement.
2. Product requirements come only from the main discovery documents one level up.
3. Do not mirror the legacy module layout, class names, protocols or storage formats in Ziggletron 2.0 merely because they exist here.
