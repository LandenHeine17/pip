Google

Connect household members' Google accounts, for their calendars and to-dos

1 · Set up Google for Pip (once)

Show the steps (about 10 minutes, free)
  1. Open Google Cloud: new project, name it Pip, Create.
  2. Turn on the Google Calendar API and the Google Tasks API (Enable on each).
  3. Google Auth platform → Get started: app name Pip, your email, Audience External, finish. Then under Audience press Publish app, so sign-ins don't expire after 7 days. (Google will call it "unverified": that's fine for your own app; you just click Advanced → Continue when signing in.)
  4. Clients → Create client → type Desktop app, name Pip → Create. Copy the Client ID and Client secret into the boxes below.
Saved only in Pip's secrets file on the Pi; never shown here again.
