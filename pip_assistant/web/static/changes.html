Opens a new Claude chat in Pip's code, where you can describe what you want.

How it works

  1. Someone asks Pip for a change, or complains about something he does. He offers "Want me to write that up as a change?"
  2. If they say yes, he writes it up and Claude Hub opens a chat for it in plan mode. Its first message is his write-up, saying who asked.
  3. In that chat you answer Claude's questions and approve its plan. Nothing changes before that.
  4. Claude builds it and commits it, then asks whether to install it.
  5. This page follows it by itself. When it's live, Pip tells the room. A live change has an Undo button here.
